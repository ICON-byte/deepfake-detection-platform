# API Endpoints

Four prediction endpoints are given for detecting potentially AI-generated or manipulated content across multiple media types.

All endpoints accept the same request payload format:

```json
{
    "fileUrl": "https://example.com/file"
}
```

The `fileUrl` must point to an accessible file that the API can download and analyze.

## Common Response Format

All prediction endpoints return a response in the following format:

```json
{
    "status": "Fake",
    "confidenceScore": 92,
    "breakdown": {
        "pixelAnalysis": 0,
        "compression": 94,
        "frequency": 100,
        "metadata": 88
    }
}
```

| Field             | Description                                           |
| ----------------- | ----------------------------------------------------- |
| `status`          | Classification result returned by the model           |
| `confidenceScore` | Confidence percentage for the prediction              |
| `breakdown`       | Additional analysis metrics generated by the pipeline |

---

## POST `/predict-audio`

Analyzes an audio file for signs of synthetic speech, voice cloning, or other audio deepfake techniques.

### Process

1. Downloads the audio file from the provided URL.
2. Runs the audio through the deepfake audio detection model.
3. Calculates a confidence score indicating the likelihood that the audio is AI-generated or manipulated.
4. Returns the prediction result along with a breakdown of analysis metrics.

### Possible Errors

| Status Code | Description                        |
| ----------- | ---------------------------------- |
| `400`         | Audio file could not be downloaded |
| `500`         | Internal audio processing error    |

---

## POST `/predict-image`

Analyzes an image for visual indicators of deepfake manipulation.

### Process

1. Downloads the image from the provided URL.
2. Detects faces within the image.
3. Runs detected faces through the deepfake vision model.
4. Generates a confidence score indicating the likelihood of manipulation.
5. Returns the result and analysis breakdown.

### Possible Errors

| Status Code | Description                          |
| ----------- | ------------------------------------ |
| `400`         | Image could not be downloaded        |
| `422`         | No face detected or image unreadable |
| `500`         | Internal image processing error      |

---

## POST `/predict-video`

Analyzes video content for deepfake manipulation.

### Process

1. Downloads the video from the provided URL.
2. Extracts and analyzes frames.
3. Detects faces across the video.
4. Runs facial data through the deepfake detection model.
5. Returns a confidence score and prediction result.

### Possible Errors

| Status Code | Description                          |
| ----------- | ------------------------------------ |
| `400`         | Video could not be downloaded        |
| `422`         | No face detected or video unreadable |
| `500`         | Internal video processing error      |

---

## POST `/predict-text`

Analyzes text content for characteristics commonly associated with AI-generated text.

### Process

1. Downloads the text file from the provided URL.
2. Extracts the text content.
3. Runs the content through the text detection model.
4. Calculates a confidence score.
5. Returns the prediction and analysis breakdown.

### Possible Errors

| Status Code | Description                       |
| ----------- | --------------------------------- |
| `400`         | Text file could not be downloaded |
| `422`         | Text is empty or unreadable       |
| `500`         | Internal text processing error    |

---
## Additional Requirements

- Uploaded files should be kept within a reasonable size limit
- The `breakdown` object may not be necessary.
